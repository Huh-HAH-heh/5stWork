# Лабораторная работа №7 — «Личная библиотека» 📚

Консольное приложение для учёта домашней библиотеки. Каталог книг хранится в JSON, заметки и рецензии — в TXT, статистика чтения по месяцам — в CSV.

## Структура проекта

```text
7PersonalLibrary/
├── README.md                         # описание, дерево проекта и обоснование структуры
├── pyproject.toml                    # метаданные, зависимости, сборка и настройки pytest
├── .gitignore                        # исключения для окружения, кешей и рабочих данных
├── main.py                           # точка входа: python main.py
├── data/
│   └── .gitkeep                      # сохраняет пустую папку данных в Git
├── src/
│   └── personal_library/
│       ├── __init__.py               # публичные классы пакета
│       ├── __main__.py               # запуск через python -m personal_library
│       ├── models.py                 # модель данных Book
│       ├── storage.py                # функции чтения и записи JSON, TXT и CSV
│       ├── library.py                # бизнес-логика класса Library
│       └── cli.py                    # консольное меню и обработка ввода
└── tests/
    ├── conftest.py                   # общие фикстуры pytest
    ├── test_book.py                  # тесты модели Book
    ├── test_storage.py               # тесты файлового хранения
    └── test_library.py               # тесты бизнес-логики Library
```

### Обоснование структуры

- `src/` содержит только исходный код. Код не смешивается с пользовательскими файлами и тестами.
- `tests/` отделена от приложения. Pytest запускает тесты из этой папки, а `tmp_path` создаёт временные данные, не затрагивая рабочую библиотеку.
- `data/` хранит изменяемые JSON/TXT/CSV. Git игнорирует сами данные, но отслеживает `.gitkeep`, поэтому пустая папка остаётся в репозитории.
- `models.py`, `storage.py`, `library.py` и `cli.py` разделяют модель, файловые операции, бизнес-логику и интерфейс. Класс `Library` не работает с файлами напрямую — он вызывает функции `storage`.
- `main.py` только запускает интерфейс. Конфигурация сборки, зависимости и pytest собраны в `pyproject.toml`.

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -e ".[dev]"
py main.py

# Альтернатива: установленная консольная команда
personal-library

# Тесты
py -m pytest -v
```

В Linux/macOS активировать окружение можно командой `source .venv/bin/activate`.

При первом добавлении книги, заметки или статистики папка `data/` и нужный файл создаются автоматически.

## Форматы хранения

- `data/books.json` — список книг со всеми полями модели.
- `data/notes.txt` — заметки формата `[YYYY-MM-DD HH:MM] «Название»: текст заметки`.
- `data/reading_stats.csv` — строки `month,books_read,pages_read`.

Используется UTF-8. JSON записывается с `ensure_ascii=False` и `indent=2`; CSV открывается с `newline=""`.

## Проверки

Тесты проверяют сериализацию Book, отсутствие файлов, сохранение кириллицы, пропуск некорректных строк TXT, создание CSV-заголовка и типы чисел, а также сохранение, поиск, удаление и подсчёт статистики. Все тесты используют временные каталоги и не изменяют `data/`.
